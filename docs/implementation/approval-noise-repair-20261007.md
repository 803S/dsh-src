# local.117：减少无效审批，恢复低影响验证

## 修复内容

- 明确的人类单资产任务从宿主原始用户消息接入出口范围，不再先让模型提交一张重复范围单。单 URL 保留协议和端口；裸域仅默认 HTTP/HTTPS；只有显式通配域或人工 ASSET 确认才覆盖子域。不从模型目标、工具参数、合成回注、引用日志或子代理消息取得授权。复杂或不明确的范围仍需人工。
- 归属确认复用原有 ASSET 流程。已待审的主域覆盖其子域，不重复堆单；不靠截取最后两段猜注册域。确认后域内新 origin 仍做 DNS 固定；域名后缀边界、被否决子域、范围变更和重启持续受约束。
- Jev 从三项重复判断（操作分类、风险、是否人工）缩为实际影响分类，文件操作另保留对象分类。风险/自动审批由宿主按该分类及既有政策确定，不再把一次只读验证同时解释成高危。有限身份输出、主机名读取、对象表示、类型计数不等于破坏性代码执行；实际删改、外发、持久化、资源耗尽或影响不明仍挂审。
- 自动许可仍受冻结请求、精确范围、方法/编码硬边界、配额、测试对象归属及版本约束；没有“看到 GET/curl 就放行”的新白名单。Jev 失败、关闭或影子模式不能自动批准。
- 不同未发送待审不互锁整个接口；同操作及人工拒绝/真正未知结果仍阻断。装饰头归并仅用于待审/拒绝去重，不让人工批准授权另一份报文。
- 主操作发送前因检查失败被阻断，记录为未发送；不把前置只读检查当作主操作已执行，也不把真正断线后的未知结果改成可重试。
- 审批卡删除旧的泛泛后果/恢复/目的模板生成逻辑；默认只显示真实目标、具体影响分类和状态，原始报文与判定记录折叠。人工等待无新增时限，挂起只影响对应工作。

## 真实验证及失败记录

全部发包在自建回环模拟服务完成，不重放用户真实资产。

1. 首轮 DSH 发现范围识别将“只暂停这两项”误当整项撤回，已收紧撤回匹配并补回归。
2. 后续 DSH/真实 Jev 矩阵发现：独立风险问题仍把 read 判为 high/unknown，改提示词仍不稳定。因此删除重复风险/许可提问，不用挑一次通过的结果掩盖矛盾。
3. 全量回归发现 Burp 前置只读检查被错误计为主请求已发送；修复后分别覆盖前置失败、主操作未知及后置核验失败。
4. 最终真实 Jev 三轮矩阵共 33 次：24 次低影响分类放行，9 次破坏性分类挂审，无 fallback。包含带破坏命令参数的 GET，不能凭方法放行。
5. 最终真实 DSH 会话 `session-b07e4a6e-f54b-4425-bb05-56b4a5368b64`，主模型 `hy4`、Jev `jev-1.13.0`：11 次低影响请求实际到达（4 条模板验证、接口探测、普通读取及 curl），两条破坏性 POST 零到达，仅产生两项风险审批，无 SCOPE 审批。挂审之后独立读取和 bash/curl 均完成。逐一核对模型调用、真实响应及服务端正文，非工具桩或模型自述。
6. 浏览器使用真实 UI bundle 与合成审批记录，验证窄屏、实际原因、默认折叠、报文展开和“未发送”状态；不操作生产审批或生产配置。

## 边界与轻量性

- 无新增依赖、数据库表或常驻服务；删除旧 UI 模板代码，复用既有审批账本与用户命令。
- 不修改供应商、废弃 FOFA 配置、生产 Jev 配置、Burp 服务或历史人工决定；旧待审不自动发送，不给用户等待设置有效期。
- 自然语言范围接入只处理明确、简单的初始指定；复杂范围及既有范围的撤回使用原显式范围命令，不宣称能完整理解任意授权合同或所有自然语言变更。
- 这些结果证明所列场景，不是对任意脚本、服务端副作用或模型准确率的“零漏判”保证；真实影响未知继续交人工。

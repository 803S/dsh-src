# local.125：单一目标与 localhost 混淆修复

## 范围

针对会话7302f42f审计中的目标混淆、网关来源、扫描噪音和研究状态问题。用户明确暂缓明文key/脱敏专项：本轮未修改密钥或脱敏规则，也未改上游供应商、宿主通用重试/压缩。没有重放真实靶场请求。

## 实施

- 公共目标检查 `target-context.js`：远程目标的网页地址不能授予localhost/127网段/IPv6回环/数字别名权限；只有已明确授权的精确本机origin或隔离测试开关可接受回环。保留DNS固定、非公网IP拒绝、目标协议/端口限制。禁止通过URL替换“修复”目标。
- 显式浏览器导航/src_http在工具接入时检查；JS脚本、重定向、资源加载仍在实际出网网关检查，不静态猜测任意JS意图。
- 浏览器在串行工具操作窗口内订阅宿主网关拒绝记录，直接展示拒绝origin/reason以及“本地阻断、未发出”；保留原生MCP value，不把目标页面自报的文本当可信网关记录。最多收集256条/窗口，呈现聚合摘要。窗口可能含自动后台请求，明确不代表本次全部请求未发送。
- 成功HTTP正文、证据回读及浏览器文本含回环地址时标注执行上下文，不把配置地址当目标拓扑证明。
- set_goal_target/add_asset明确不扩大授权；src_state及Web显示目标记录的scopeOrigin。用户模糊“继续/使用域名”不能由模型升级为新增端口。
- 扫描线索解析修正过度转义；404/超时不构造多后端线索，成功页面的共同SPA模板和通用静态目录不构成多应用证明；length缺失为null/unknown，不再写0；响应/失败/未调度/输入超限分开统计。
- 扫描目标超时复用onSend计时，不包含审核与本地调度等待。
- 网关证据在唯一活动方向时绑定intent，不在多方向时猜归属；src_state/概览展示未关联证据、planned已有执行证据、研究记录缺失。不自动标verified/completed，不把重复记录层当独立测试计数。
- 畸形空工具名/ID明确为MALFORMED_TOOL_CALL，不归成未适配工具或让模型换网络通道。
- 历史briefing声明旧ID来自来源会话；开局仅展示12项经验索引，保留完整库检索，不修改历史记录。方法/分工推荐仍由主模型采纳，不承诺模型绝不再错误推理。

## 保留边界

- 不自动修改目标页面的API地址、代理请求到其他端口或“修正”用户本机服务。
- 旧会话中的错误结论/错误资产不会被静默删除；新的状态提示不等于所有历史记录自动纠正。
- 仍有不同层的HTTP记录；本轮不做破坏性历史去重。浏览器网关记录是操作窗口关联，不宣称每一条自动请求都可归为某个JS调用。
- 无模型完整复跑验证，不能把测试通过当成“确保所有漏洞都找到”或“模型永不乱猜”。
